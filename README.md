# TaskFlow Control Center

Aplicație web statică pentru monitorizarea task-urilor personale, ale echipei și ale proiectelor, cu sincronizare EtherCalc.

## Noutate
- Light / Dark mode din bara de sus;
- tema aleasă este salvată în `localStorage`;
- la prima utilizare se respectă automat tema sistemului.

## Surse live EtherCalc
- Personale: https://calc.domainepublic.net/0y4rcf8ujgyf
- Echipă: https://calc.domainepublic.net/5wt3mqujqovw
- Proiecte: https://calc.domainepublic.net/if1566u5k4ly

## Rulare
Publică `index.html`, `styles.css` și `app.js` în același folder pe un server static.


## Limbă / Language

Interfața include un buton **🌐 EN / RO** în bara de sus. Schimbarea limbii actualizează instantaneu textele, butoanele, filtrele, statusurile, prioritățile, mesajele, dialogurile și antetele exportului Excel între română și engleză. Preferința este memorată local în browser.

## Temă

Butonul Dark / Light păstrează tema aleasă în browser și funcționează independent de limba interfeței.
